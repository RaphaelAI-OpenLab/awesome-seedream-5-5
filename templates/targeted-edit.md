# 单一区域编辑 / One-region edit

**本仓库原创练习配方 · 未执行 · 不对应来源样张的原始输入**

## 中文指令

```text
使用上传的照片，只把左侧陶瓷杯的把手改为深蓝色。杯身、桌面、背景、阴影与取景保持原样。不要增加文字或新物体。输出与输入相同的画幅。
```

## English prompt

```text
Use the uploaded photograph. Recolor only the handle of the ceramic cup on the left to navy blue. Preserve the cup body, tabletop, background, shadows and framing. Add no text or objects. Keep the input aspect ratio.
```

## 验收项

1. 对齐输入与输出，检查目标区域是否改变。
2. 检查目标区域以外是否出现新物体或颜色漂移。
3. 保存原始输入、指令、模型版本与输出文件。

如服务没有对应模型或输出开关，不以提示词文字代替服务能力。生成结果需要人工检查。
